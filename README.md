# 发票信息提取工具

一个简单易用的 PDF 电子发票信息提取工具，支持批量上传并导出 Excel。

## 功能特点

- 📤 **批量上传**：支持同时上传多个 PDF 发票文件
- 🔍 **智能提取**：自动识别并提取发票关键信息
- 📊 **Excel 导出**：一键导出为标准 Excel 格式
- 🎨 **友好界面**：简洁美观的 Web 操作界面
- 💻 **本地运行**：数据不离开本地，安全放心

## 提取字段

### 基本信息（合并单元格展示）
| 字段 | 说明 |
|------|------|
| 文件名 | 原始 PDF 文件名 |
| 发票代码 | 10-12 位发票代码 |
| 发票号码 | 8-20 位发票号码 |
| 开票日期 | YYYY-MM-DD 格式 |
| 购买方名称 | 购买方公司名称 |
| 购买方税号 | 纳税人识别号 |
| 销售方名称 | 销售方公司名称 |
| 销售方税号 | 纳税人识别号 |
| 金额合计 | 不含税金额总计 |
| 税额合计 | 税额总计 |
| 价税合计 | 含税总金额 |
| 备注 | 解析异常信息 |

### 明细项目（每个项目一行）
| 字段 | 说明 |
|------|------|
| 项目名称 | 商品或服务名称 |
| 规格型号 | 规格型号（如有） |
| 单位 | 计量单位 |
| 数量 | 数量 |
| 单价 | 不含税单价 |
| 金额 | 不含税金额 |
| 税率 | 税率/征收率 |
| 税额 | 税额 |

### Excel 展示规则
- 一张发票有多个明细项目时，每个明细占一行
- 基本信息列（前8列）和合计列（后4列）自动合并单元格
- 方便查看同一张发票的所有明细项目

## 快速开始

### macOS / Linux

```bash
# 赋予执行权限
chmod +x start.sh

# 启动程序
./start.sh
```

### Windows

双击运行 `start.bat`

### 手动启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务
python app.py
```

启动后在浏览器中打开 http://localhost:5000 即可使用。

## 系统要求

- Python 3.8+
- 现代浏览器（Chrome、Firefox、Safari、Edge）

## 使用说明

1. 启动程序后，浏览器会自动打开或在控制台显示访问地址
2. 点击上传区域或拖拽 PDF 文件到上传框
3. 支持多选，可一次上传多张发票
4. 点击「开始处理」按钮
5. 处理完成后自动下载 Excel 文件

## 打包为独立应用

如需打包为可执行的独立应用程序，可使用 PyInstaller：

```bash
# 安装 PyInstaller
pip install pyinstaller

# 打包
pyinstaller --onefile --windowed --name "发票提取工具" app.py
```

打包后的可执行文件位于 `dist/` 目录下。

## 注意事项

- 仅支持 PDF 格式的电子发票
- 单文件大小限制 16MB
- 每日免费 API 额度有限，大量使用请考虑本地解析
- 不同版式的发票可能需要调整解析规则
